Insert Sorted

Implement the destructor and InsertSorted on a DoublyLinkedList<T> class template that maintains its elements in ascending sorted order. Each call to InsertSorted creates exactly one new DNode<T> on the free store and links it into the correct position so the list remains sorted after every insertion.

For example, starting from an empty list:
InsertSorted(3) produces {3}
InsertSorted(1) produces {1, 3}
InsertSorted(5) produces {1, 3, 5}
InsertSorted(2) produces {1, 2, 3, 5}

DNode<T>
Public interface

DNode(T data)
Provided. Initializes data with the given value; next and prev remain nullptr.

DNode(T data, DNode<T>* next, DNode<T>* prev)
Provided. Initializes data, next, and prev with the given values.

Public data members
- data — T. Provided. The value stored in the node.
- next — DNode<T>*. Provided. Pointer to the next node in the list; nullptr for the last node.
- prev — DNode<T>*. Provided. Pointer to the previous node in the list; nullptr for the first node.

DoublyLinkedList<T>
Public interface

DoublyLinkedList() = default;
Provided. Default constructor. The in-class initializers leave head_ and tail_ as nullptr.

~DoublyLinkedList();
Destructor. Traverses the list from head_ and deletes every node so no memory is leaked.

void InsertSorted(const T& value);
Creates exactly one new DNode<T> on the free store holding value and links it in so the list remains in ascending sorted order. Updates head_ and tail_ as needed. All next and prev pointers must be correct after every insertion.

Private data members

head_ — DNode<T>*. Provided. Pointer to the first node, or nullptr for an empty list. The autograder reads and seeds this member directly, so do not rename it, and keep it private.

tail_ — DNode<T>*. Provided. Pointer to the last node, or nullptr for an empty list. The autograder reads and seeds this member directly, so do not rename it, and keep it private.

head_ and tail_ must remain private data members; this is graded.

Write both member function definitions in includes/doubly_linked_list.hpp, below the class declaration. Each definition needs its own template <typename T> header, and the qualified names are DoublyLinkedList<T>::~DoublyLinkedList and DoublyLinkedList<T>::InsertSorted.

Edge cases for InsertSorted
- Inserting into an empty list: the new node becomes both head_ and tail_.
- Inserting before the current head (value is smaller than all existing elements): update head_.
- Inserting after the current tail (value is larger than all existing elements): update tail_.
- Inserting in the middle: update both neighbors' pointers.
- Duplicate values may be inserted either before or after existing nodes with the same value.
- Each call to InsertSorted must allocate exactly one new node. Relink the existing nodes; do not rebuild or reallocate them or shift values between them. The existing nodes must keep their addresses.

Important notes
Your submission is also run under AddressSanitizer: a destructor that does not free every node, allocating more than one node per insertion, or losing nodes that should survive is reported as a memory error. Implement the pointer manipulation yourself; standard library containers and algorithm functions may not be used to do the work for you.

Constraints
Your solution must compile with clang++ using the c++20 standard, without errors when using the flags: -Wall -Wextra -Werror -pedantic. You may only include the following headers: "dnode.hpp", "doubly_linked_list.hpp", <iostream>
