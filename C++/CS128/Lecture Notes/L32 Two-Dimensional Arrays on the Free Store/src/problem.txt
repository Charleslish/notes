Vineyard Rows
A vineyard is planted in rows, and every row holds the same number of vines. At harvest, the grower records the grams of grapes each vine yields. The class Vineyard keeps those yields on the free store as a two-dimensional array: the private data member yields_, of type int**, holds the address of an array of row pointers, and each element of that array holds the address of one row, an array of int whose elements are the yields of that row's vines. yields_[row][vine] is the yield of vine vine in row row. The private data members rows_ and vines_ hold the number of rows and the number of vines in each row.

A Vineyard is the owner of its rows and of its array of row pointers: the constructor creates them with new[], and the destructor deletes them with delete[]. Each row is deleted before the array of row pointers, because the array of row pointers holds the only copies of the rows' addresses. A vineyard with no rows holds nullptr, 0 and 0. A vineyard is one piece of land, so a Vineyard is never copied.

The starter header vineyard.hpp declares every member of Vineyard in the tables below. You write the definition of each member function in vineyard.cc, the constructor, the destructor and the private member function included.

Otherwise it creates a new array of rows row pointers and a new row of vines elements for each of them, every yield 0, even when rows and vines equal rows_ and vines_. It copies every yield whose row is less than both numbers of rows and whose vine is less than both numbers of vines into the same row and vine of the new rows. It then deletes the old rows and the old array of row pointers by calling DeleteRows, stores the new array's address in yields_, sets rows_ and vines_ to rows and vines, and returns true. A vineyard that holds nullptr, 0 and 0 receives new rows whose yields are all 0.

Constraints
Your code must compile with clang++ using the c++20 standard and -stdlib=libc++, without errors under -Wall -Wextra -Werror -pedantic -Wuninitialized. Your code is also compiled with AddressSanitizer, which reports memory errors such as reading an array after it is deleted, deleting an array twice, deleting an array with delete instead of delete[], and, through LeakSanitizer, many arrays that are never deleted, and UndefinedBehaviorSanitizer, which reports operations such as dereferencing a null pointer. Neither detects every invalid operation. The Run button shows their reports.

The provided header declares the copy constructor and copy assignment with = delete, so the compiler rejects any copy of a Vineyard; pass one by reference.

Declare every member exactly as the starter header declares it, including both declarations written = delete. Every member function of Vineyard is defined in vineyard.cc. The data members of Vineyard are yields_, rows_ and vines_, and its constructors and public member functions are those in the table. You may declare private member functions of your own in Vineyard. The autograder sets yields_, rows_ and vines_ directly before each function call, giving the vineyard rows and an array of row pointers it created itself, so every member function must read the state of a vineyard from those data members alone.

vineyard.hpp and vineyard.cc may include only the header "vineyard.hpp".

A member function may call another member function or construct a Vineyard of its own. Four rules are graded checks worth points of their own: code that breaks one loses that check's points, and every test still runs. The constructor initializes rows_ and vines_ in its member initializer list and creates its arrays with new[] in its body, so its member initializer list does not name yields_. Every array is created only with new[] and deleted only with delete[]: a library function or type that obtains or manages memory, and a library container, are not permitted. The loops that copy the yields are your own: a library function that copies, fills, searches, counts, compares, sorts, combines, or removes the elements of an array is not permitted. The keyword try may not appear in your code.
