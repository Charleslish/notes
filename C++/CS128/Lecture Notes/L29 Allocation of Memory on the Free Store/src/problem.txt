Tide Log
Overview
A tide gauge on a harbor wall measures the height of the water once an hour, in centimeters above or below a fixed 
mark, and puts those measurements into a log. Readings are inserted into the log one at a time at various positions 
in the sequence. It is not known in advance how many readings a log will hold, so the log keeps them in a dynamic 
array on the free store.

The provided header includes/tide_log.hpp defines the struct TideLog, whose three members describe a log. 
int* heights = nullptr; holds the address of the first element of an array created with new[], or nullptr when the 
log holds no array. 
unsigned int size = 0; is the number of heights recorded, which occupy elements 0 through size - 1 in time order. 
unsigned int capacity = 0; is the number of elements the array can currently hold.

Write the four functions below in src/tide_log.cc that manage the dynamic array of heights.

Functions to Implement
Function	Description
TideLog MakeLog(unsigned int capacity)	
Returns an empty log whose size is 0, whose capacity is capacity, and whose array can hold capacity elements.

void Reserve(TideLog& log, unsigned int capacity)	
Overwrites the log's array with a new array that has space for capacity heights if the new capacity is greater than 
the old capacity. This function copies the log.size heights from the old array into the new array, 
updates log.heights, and deletes the memory holding the old array.

bool InsertAt(TideLog& log, unsigned int index, int height)	
Inserts height so that it becomes element index, and shifts the heights from index onwards to the right. 
An index greater than log.size changes nothing and returns false; an index equal to log.size places height after 
the last height. If the log is full, InsertAt creates a new array of twice the capacity, or of 1 element when the 
capacity is 0, updates and deletes the old array, then performs the shift procedure as before. If the function added 
an element to the array, it adds 1 to the size and returns true.

void Release(TideLog& log)	
Deletes the log's array with delete[] and makes log empty.

Examples
Each row shows a log as its heights, its size and its capacity, before and after one function call.

Log before	Function call	Returns	Log after	Array
none	MakeLog(3)	a log	no heights, size 0, capacity 3	a new array of 3 elements
none	MakeLog(0)	a log	the empty log	none; heights is nullptr
{88, 71}, size 2, capacity 2	Reserve(log, 6)		{88, 71}, size 2, capacity 6	a new array of 6 elements; the old array is deleted
{88, 71}, size 2, capacity 6	Reserve(log, 4)		unchanged	the same array
{130, 104, 52}, size 3, capacity 5	InsertAt(log, 1, 118)	true	{130, 118, 104, 52}, size 4, capacity 5	the same array
{-9, -4, 3}, size 3, capacity 3	InsertAt(log, 2, 0)	true	{-9, -4, 0, 3}, size 4, capacity 6	a new array of 6 elements; the old array is deleted
the empty log	InsertAt(log, 0, 27)	true	{27}, size 1, capacity 1	a new array of 1 element
{130, 104, 52}, size 3, capacity 5	InsertAt(log, 5, 118)	false	unchanged	the same array

The growth in the sixth row follows the order every replacement of an array follows: create the larger array, 
copy the heights into it, delete the old array, store the new address, and record the new capacity.

Constraints
Write the function bodies in src/tide_log.cc and don't modify includes/tide_log.hpp. You may add functions of your 
own if you declare each one in includes/tide_log.hpp as well.
The definitions of Reserve and InsertAt each create the new array with new[] and delete the old array 
with delete[] themselves.
The only header that src/tide_log.cc and includes/tide_log.hpp may include is "tide_log.hpp".
