2.2
Overview
The two repositories are at /home/player/projects/warehouse and /home/player/code/inventory. The first one is there to be read. Questions 1 to 4 ask what git reports about it, and you type those four answers into the boxes under the table. The second one is where you work: questions 5 to 10 are graded from the state you leave that repository in, not from what your terminal printed.

The terminal runs one command at a time, and refuses a line holding >, <, |, ;, &, $, or `. A program named write-line.sh is waiting in your home directory, and you run it by its pathname and hand it two arguments: ~/write-line.sh notes.txt anchor-2031 makes notes.txt hold the single line anchor-2031 and nothing else, in the directory you are standing in, and creates the file if it is not there yet. It is short enough to read, and cat ~/write-line.sh prints it. Every line named below is a whole line, and it is the only line its file holds.
